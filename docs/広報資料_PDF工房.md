## 2. 作成の経緯

塾の仕事では、教材やプリントを PDF で扱う場面が毎日のようにあります。

- 複数の資料を1つにまとめる、必要なページだけを抜き出す
- スキャンした教材の向きを直す、余白を切り落とす
- 解答や連絡事項を書き込む
- 一度書き込まれた赤ペンなどの書き込みを消して、もう一度使える形に戻す

これまでは古い市販の PDF ソフトを使っていましたが、次のような不便がありました。

- 文字を書き込むまでの手順が多く、少しの書き込みでも時間がかかる
- 書き込みを消す、手書きの部分を消すといった作業がしにくい
- 奇数ページだけ・偶数ページだけを回転する、余白を切り落とす、といったよく使う操作に、毎回手間がかかる

そこで、**塾の現場でよく使う機能だけを集め、迷わず使える PDF アプリ**を自分たちで作ることにしました。
開発には AI（コーディング用の AI アシスタント）を活用し、現場で使いながら「ここが使いにくい」「この操作をよく使う」という声をすぐに反映して改良しています。

### 開発の流れ（事実として使える出来事）

| 日付 | 内容 |
|---|---|
| 2026-11-05 | 開発開始。ページ操作・書き込み・消去・PDF への変換・インストーラーまでを作成 |

| 2026-11-06 | 1.3。現場の要望を受け、「ページの回転」「ページのトリミング」で、ページ範囲と奇数・偶数ページを指定できるようにした |

## 3. 作成の目的

1. **先生の準備時間を減らす**
   教材準備の細かい作業を短くし、その分の時間を生徒と向き合うことに使えるようにします。
2. **だれでも迷わず使える**
   よく使う操作を、少ない手順でできるようにしました。画面とメニューはすべて日本語です。
3. **安心して使える**
   ファイルはすべてパソコンの中で処理し、インターネットには送りません。生徒の答案や個人情報を含む書類も、外部のサービスに上げずに扱えます。
4. **ほかの先生・教室にも役立てる**
   無料で公開し、ソースコードも公開しています。同じような悩みを持つ先生や教室運営者にも使っていただけます。

## 4. できること

| 分類 | 内容 |
|---|---|
| ページの整理 | 並べ替え（ドラッグ）、回転、削除、抽出、分割、空白ページの挿入 |
| 回転・トリミングの細かい指定（1.3） | ページ範囲、奇数ページのみ、偶数ページのみ、縦向き・横向きのページを指定して回転・トリミング。余白は mm で指定でき、白い余白の自動検出もできる |
| 結合 | PDF や画像を、ページ一覧にドラッグするだけで結合 |
| 抽出 | ページ一覧から、デスクトップやフォルダへドラッグすると、そのページだけの PDF ができる |
| 書き込み | クリックした場所にそのまま文字を入力。ペン、四角、丸、マーカー、画像（ハンコ） |
| 消去 | 消しゴム、範囲を囲んで消す（四角・丸・投げ縄） |
| 書き込みの自動消去 | 赤ペン・青ペンの書き込みを色で見分けて消す、PDF のペン注釈をまとめて削除 |
| PDF への変換 | Word・Excel・PowerPoint、画像（JPG・PNG など）、テキストを PDF に変換。まとめて1つの PDF にもできる |
| 書き出し・印刷 | ページを画像（PNG / JPEG）で書き出し、印刷 |
| 見た目 | 色味の切り替え（ライト・ダーク・ベージュなど） |

書き込みは、保存するまでは何度でも動かしたり直したりできます。保存すると PDF に書き込まれ、ほかの PDF ソフトでも同じように表示されます。
操作はほぼすべて Ctrl+Z で元に戻せます。

## 5. かんたんな使い方

### インストール

1. ダウンロードページから「PDF工房 セットアップ」（`PDFKoubou_Setup_<版>.exe`）をダウンロードします。
2. ダウンロードしたファイルを開きます。管理者権限は要りません。
3. 青い画面で「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押して進みます。
   （無料公開のため、有料の電子署名をしていないことによる表示です。）
4. 画面の案内に沿って進めると、デスクトップに「PDF工房」のアイコンができます。

新しい版が出たときは、新しいセットアップを実行するだけで上書き更新されます（設定はそのまま残ります）。

### 基本の操作

| したいこと | 操作 |
|---|---|
| PDF を開く | PDF をウィンドウにドラッグする。Word や画像も、ドラッグすると自動で PDF に変換して開く |
| 文字を書き込む | 「テキスト」を選び、書きたい場所をクリックして、そのまま入力 |
| 書き込みを消す | 「消しゴム」でなぞる。または「範囲消去」で囲む |
| ページを並べ替える | 左のページ一覧でドラッグ |
| PDF を結合する | 左のページ一覧に、別の PDF をドラッグ |
| ページを抜き出す | 左のページ一覧から、デスクトップへドラッグ |
| 奇数ページだけ回転する | 「ページ」→「ページの回転」で、適用先を「奇数ページのみ」にする |
| 余白を切り落とす | 「ページ」→「ページのトリミング」で、上下左右の余白を指定する |
| 保存する | Ctrl+S |

困ったときは、アプリの「ヘルプ」→「使い方」（F1 キー）で操作の一覧を見られます。

## 6. 注意事項（お知らせに含めるもの）

- 無料・無保証で提供しています。大切なファイルは、元のファイルを残してから編集してください。
- Word・Excel・PowerPoint を PDF に変換するには、パソコンに Microsoft Office が入っている必要があります。
- 「色ペンの書き込みを消す」を使ったページは画像になり、文字の検索・選択ができなくなります。
- 黒の鉛筆やボールペンの手書きは、印刷の文字と自動では区別できません。消しゴムか範囲消去で消してください。
- 一部のパソコン（Windows 11 の「スマート アプリ コントロール」がオンのもの）では、インストールできないことがあります。

## 7. 文章を書くときの決まり

### トーン

- 誠実でわかりやすく、落ち着いた日本語にする。親しみやすさは加えてよいが、軽すぎる表現は避ける。
- Astras Group の考え方（AI とアプリは、目標・行動・振り返りをつなぐ「道具」）に合わせる。
- 主役は先生と生徒。「便利なツールができた」だけでなく、「準備の時間を生徒と向き合う時間に」という目的が伝わるようにする。

### 書かないこと・言い換えること

| 避ける | 理由・言い換え |
|---|---|
| 「Acrobat」「Adobe」など、他社の製品名・会社名 | 関係があるように読まれるため。「市販の PDF ソフト」と書く |
| 「ECC」の名前・ロゴ | Astras Group の発信では使わない |
| 「必ず」「絶対」「誰でも簡単に」「完全無料で何でもできる」 | 誇張になるため。「よく使う操作を、少ない手順でできるようにしました」など |
| 「Acrobat の代わりになる」「有料ソフトはもう不要」 | 他社製品との比較・断定になるため。機能を具体的に書く |
| 「安全性を保証」「ウイルスの心配はありません」 | 保証になるため。「ファイルはパソコンの中だけで処理し、インターネットに送りません」と事実を書く |
| 「AI が全部作った」 | 正確でないため。「AI を活用して開発」「現場の声を反映して改良」 |

### 書いてよい事実

- 塾の現場で実際に使いながら作ったこと
- AI を活用して、短い期間で開発・改良していること
- 無料で、ソースコードも公開していること
- ファイルを外部に送らないこと
- 画面とメニューがすべて日本語であること
